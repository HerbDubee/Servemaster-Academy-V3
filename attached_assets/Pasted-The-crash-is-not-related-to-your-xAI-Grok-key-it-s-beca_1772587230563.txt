The crash is not related to your xAI/Grok key — it's because your code is using the OpenAI SDK/client (openai npm package), but the API key environment variable is set up for OpenAI (OPENAI_API_KEY), not xAI.
Look at the key error in the logs:
textOpenAIError: Missing credentials. Please pass an `apiKey`, or set the `OPENAI_API_KEY` environment variable.
This comes from the OpenAI client initialization in /app/node_modules/openai/client.js (line ~94), triggered from your server.js (around line 16 or 59). Your code is likely doing something like:
JavaScriptconst openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,  // <-- this is undefined/missing
  // or no apiKey passed, so it falls back to env var
});
Even though you're calling xAI's endpoint (https://api.x.ai/v1), the official OpenAI SDK requires an OPENAI_API_KEY env var (or explicit apiKey in constructor) for authentication — it doesn't know about XAI_API_KEY.
xAI's API is OpenAI-compatible (same /v1/chat/completions endpoint format), but you need to configure the client properly to point to xAI's base URL and use your xAI key.
Quick Fix: Update Your Code to Use xAI Correctly
In server.js (or wherever you initialize the client), change it to:
JavaScript// Option 1: Use OpenAI SDK with custom base URL (recommended - minimal change)
const { OpenAI } = require('openai');  // or import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.XAI_API_KEY,          // Use your xAI key here
  baseURL: 'https://api.x.ai/v1',           // Point to xAI endpoint
});

// Then use client.chat.completions.create(...) as normal
